# Security policy

## Status
Early-stage public open-source project, not independently security audited. Do not store irreplaceable information without a separate tested backup.

## Supported versions
There is no stable released version and no supported security maintenance window yet.

## Reporting vulnerabilities
**Do not put exploitation details or user data in public issues.** Use this repository's **Security** tab to submit a private vulnerability report if private reporting is enabled. If that option is unavailable, avoid disclosing exploit details or personal data in public issues; the maintainer should enable private reporting.

No email address, response SLA or bug-bounty promise is asserted.
